# COIS-3060-Workshop4
## How to Use 
### Add a Book 
``` 
python add_book.py 
``` 
### Search for Books 
``` 
python search_books.py 
``` 
### List All Books 
``` 
python list_books.py 
``` 
### Delete a Book 
``` 
python delete_book.py 
``` 
## File Format 
Books are stored in `books.txt` with the format: 
``` 
Title, Author, Year 
``` 
## Example 
``` 
1984, George Orwell, 1949 
To Kill a Mockingbird, Harper Lee, 1960
